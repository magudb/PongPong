# Blob size limits of tools/ci/size_guard.py (REPO-01; policy in docs/DEVELOPMENT.md, "Repository size").
#
#   default <size>       limit of a plain blob whose path matches no line below
#   lfs-object <size>    limit of the object a Git LFS pointer names
#   <size> <pattern>     limit of a plain blob on a matching path; the first matching line wins
#
# Patterns are repo-relative: `**` spans directories, `*` and `?` stay inside one path component.
# Only blobs that a commit adds or changes are measured, so files committed before the guard keep working until
# they are changed. Raise a line in the same commit as the file that needs it and say why in the message.

default 1MiB
lfs-object 64MiB
