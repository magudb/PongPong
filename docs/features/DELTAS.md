# DELTAS - what differs between the reviewed content pack and the repo

The feature content (home tiers, furniture, clothing, materials, recipes, shops, loot, sets, four quests, three builder dialogues, 906 localization rows) was written and
reviewed as a separate pack (`PongPong_lift/features/FR/fc`, "FC").  Package **F1-feature-data** COPIED it into the repo; this file lists every difference
between the pack and the repo, with the reason and the package that owns the change.  CD1-CD12 are the first-round deltas of the addendum (2.7), CD13-CD20 the deltas of the review.
"State" says where the delta lives in the repo and which validator rule proves it (`tools/features/validate/run_validate.sh --stage f1`; rule ids as printed in its report).
