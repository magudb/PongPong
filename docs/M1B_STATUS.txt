Economy API extension

consume_backpack_items(needs, commit, gold_cost=0) now optionally debits gold in
the same commit. receive_backpack_item(item, amount, commit) handles silent chest
withdrawals. defer_notifications(action) runs an already-validated transaction
before EconomyManager observers; after_transaction(action) lets related loot
announcements join it. These helpers do not replace validation or add rollback.
Storage owners joining a loot transaction should also defer their notifications
through after_transaction so observers see the completed transaction.
