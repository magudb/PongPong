Art provenance and packaging
  Four masters have true alpha, near/full-opacity painted surfaces and no opaque
  pixels touching their outer canvas edges. Exact prompts, ordered reference
  files, master sizes and SHA256 hashes are recorded in prompts.json. Future
  layer-authoring and fit-repair templates are explicitly marked unexecuted.
  All 52 lossless WebP exports match manifest dimensions and use Godot lossless
  import mode 0 for the review UI. inventory.csv identifies
  each source/export and existing, planned or presentation-only item references.
  The standalone packer writes only assets/art_studies/equipment/. Live character,
  clothing, prop and item catalogs are unchanged. Python compilation and
  git diff --check pass.

Limits
  The studio changes between flattened illustrations; it does not mix garment
  layers, animate equipment, synchronize real action grips, apply item effects or
  write wardrobe saves. One- and two-hand poses communicate art intent. The rig
  example contains illustrative coordinates and cannot be used as authored data.
  Small-scale silhouette views are review thumbnails, not a measurement of normal
  world-camera scale. Resource/update limits in design.txt are future production
  targets, not performance measurements of a working equipment renderer.
